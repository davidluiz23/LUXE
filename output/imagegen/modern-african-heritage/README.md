# ALKEBULAN - Modern African heritage

Five generated desktop homepage concepts for owner selection. The existing Living Canvas implementation remains the active website.

- [01 - Earthen Atelier](01-earthen-atelier.png)
- [02 - Indigo Archive](02-indigo-archive.png)
- [03 - Bronze After Dark](03-bronze-after-dark.png)
- [04 - New Lagos](04-new-lagos.png)
- [05 - Woven Futures](05-woven-futures.png)

All five images are 1536 x 1024 PNG files. Full prompts and the input-reference paths are in prompts.json.

Art direction: 01 sculpted clay and warm light; 02 indigo textile editorial; 03 bronze and charcoal gallery; 04 expressive red and cobalt poster; 05 sculptural woven loops in ivory and deep green.

References: the selected Living Canvas screenshot and the owner's original Ijele, Durbar, and Dun Dun product photographs. These are generated design mockups, so implementation should composite the original garment files to retain exact product artwork. Surrounding architecture, metal and textiles are contemporary generated concepts.

Skills applied: imagegen and ui-design. These images are kept outside Frontend so they do not ship with the storefront.
