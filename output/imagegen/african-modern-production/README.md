# ALKEBULAN campaign assets

Generated with the built-in image generator from the user's selected `../clean-african-streetwear-v3/05-african-modern.png` and original Ijele/Durbar garment photographs.

- `pose-01.png`: the two fictional campaign models, relaxed standing pose.
- `pose-02.png`: the same models, alternate editorial pose.
- `pose-03.png`: the same models, angled back-to-back pose.
- `red-portrait.png`: the isolated glossy vermilion line portrait, reconstructed behind the models.

The PNG originals preserve alpha. Production WebP encodings live in `Frontend/assets/african-modern`. Exact generation prompts: `scripts/african-modern/asset-prompts.json`. The generated people are campaign imagery, not customers, team members, or testimonials.
