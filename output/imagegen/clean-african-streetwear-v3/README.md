# ALKEBULAN - Clean African streetwear, set 3

Five full-size desktop image concepts responding to the owner's request for cleaner, eye-catching work using community design skills.

- [01 - Living Form](01-living-form.png) - Spacious sculptural product stage; cream and terracotta.
- [02 - Studio Lagos](02-studio-lagos.png) - Quiet fashion campaign; sage and warm white.
- [03 - Cobalt Rhythm](03-cobalt-rhythm.png) - Minimal graphic art; cobalt, chalk and a single product.
- [04 - Night Edition](04-night-edition.png) - Clean dark portrait; charcoal and copper.
- [05 - African Modern](05-african-modern.png) - Airy central fashion composition; ivory and vermilion.

## Applied skills

- ui-design: aesthetic-direction.md and marketing-ui.md - whitespace, hierarchy, one dominant composition, short copy, restrained color and type.
- build-awwwards-quality-sites: one authored hero focal asset, original art direction, asset provenance and visual review. The user requested images, so implementation and motion work are deferred.
- imagegen: built-in image_gen generation, separate image per direction, one targeted spacing refinement to concept 05.

## Source and review

Full generation and refinement prompts are in prompts.json. Inputs are the existing Living Canvas screenshot, original garment photographs and, in concepts 01/03, the supplied abstract-faces artwork as a high-level form reference. These are visual concepts, not new production product photographs. Campaign people, settings and surrounding art are generated, with no actual-endorsement or historical-authenticity claims.

Visually reviewed each image for legible brand, unobstructed garment graphics, one dominant visual idea, whitespace and UI spacing. Refined concept 05's lower-left caption/button separation. All five final PNGs were checked for valid image signatures and dimensions. The live storefront and previous image sets remain unchanged. For implementation, retain original product photos and verify responsive behavior, contrast and keyboard interactions in the browser.
