# ALKEBULAN fonts

Local WOFF2 subsets of Manrope, Poppins, Instrument Serif, and Playfair Display from Google Fonts. Each family retains its SIL Open Font License here. Latin and Latin Extended cover the storefront names and naira prices. The browser downloads only faces used on the current page. Content hashes in filenames invalidate changed fonts; font-display: optional prevents late text reflow.

The existing Font Awesome Free 6.0.0-beta3 fonts are hosted here with their license. Its CSS is in `css/icons.css`; primary navigation icons use inline SVG instead.
